# Personal Zsh configuration

The preserved `.zshrc` moved here from `zsh/.zshrc`. Its content is
unchanged by the directory reorganization.

Copy or symlink `.zshrc` to `~/.zshrc` after reviewing your existing
file. This configuration includes Omarchy-specific initialization and
distribution-specific plugin paths; portability is **not yet verified**.
No installation was performed as part of this change.

[shared/starship](../starship/README.md). These are existing personal
